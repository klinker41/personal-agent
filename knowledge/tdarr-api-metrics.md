# Knowledge: Tdarr-Api-Metrics

- Tdarr queue and node processing statistics can be queried directly via the
`StatisticsJSONDB` endpoint.

- Tdarr web server responses can transiently block and exceed health check
timeouts during library scans, media extraction, or array disk spin-up.
