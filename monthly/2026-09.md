# Monthly Memory Chronicle: 2026-09

## Overview

September 2026 focused on memory subsystem refinements, architectural
modernization across media generation services, autonomous game agent
engineering, container infrastructure stability, and platform-wide codebase
audits. Major milestones included establishing a standardized Bun and Hono web
application architecture, launching and hardening the autonomous
`llm-plays-pokemon` live stream platform, unifying media generation under the
Media Studio platform, scoping audiobook workflows to generated books,
integrating Google Lyria theme music and EBU R128 loudness normalization,
hardening Gemini AI and TTS generation pipelines, refining container model
translation proxies, and completing extensive frontend and backend security
audits and remediations.

## Memory Subsystem & Consolidation

- Consolidated and deduplicated memory notes across the `knowledge/` and
  `projects/` directories into canonical reference files.
- Updated the memory consolidation engine to inject existing knowledge topic
  and project catalogs into synthesis prompts, preventing duplicate notes.
- Updated the memory daemon to resolve and include Antigravity conversation
  titles in daily consolidation summary headers.

## Architecture & Infrastructure

- Consolidated `podcast-generator` from a 6-container Python, PostgreSQL, and
  Celery stack into a unified Alpine container with file-based storage,
  subsequently migrating the backend from Node.js and Express to Bun and Hono
  with minimal dependencies and hardened file endpoints.
- Migrated `movie-generator` to Bun and Hono, eliminating bloated dependencies
  and resolving edge proxy 404 caching issues for frontend assets.
- Formalized and verified the `web-app-architecture` rule in
  `antigravity-plugin` to standardize web applications on Bun and Hono.
- Rebranded frontend components to "Media Studio", aligned architecture
  between `movie-generator` and `podcast-generator` via a comparative audit,
  and published a comprehensive `media-generator` platform README and master
  audit plan.
- Consolidated podcast file storage under `data/podcasts` in `media-generator`,
  optimizing episode loading performance with single-pass active generation
  checks and in-memory caching.
- Configured `antigravity-docker` with `--hub-port` for deterministic upstream
  port binding, removing dynamic log scraping.
- Architected custom model provider integration for `antigravity-docker` by
  transcoding Connect-RPC Protobuf streams to Anthropic and OpenAI streaming
  endpoints.
- Clarified that `antigravity-docker` does not depend on LiteLLM, relying
  instead on a native Node.js streaming transcoder proxy for external model
  translation due to Connect-RPC UI discovery and PA endpoint compatibility.
- Evaluated delegating custom model tool calls to Gemini Flash within the
  Antigravity proxy and fixed translation proxy defects in `write_to_file`
  tool execution, built-in model routing, and sub-agent model configuration
  retention.
- Redesigned the `media-generator` home screen into a responsive asymmetric
  command center dashboard and updated the podcasts list mobile card
  hierarchy.
- Diagnosed missing legacy movies caused by multi-user RBAC filtering and
  restored access by promoting the user to admin in `users.json` on disk.
- Clarified `EXTERNAL_OUTPUTS_DIR` and confirmed that model defaults originate
  in application code rather than container Dockerfiles.

## Autonomous Systems & LLM Plays Pokémon

- Architected, implemented, and verified `llm-plays-pokemon`: an autonomous,
  headless Pokémon Red live streaming engine built on Bun (v1.4.2), Python
  headless PyBoy 2.7.0, bun:sqlite with WAL mode, and static FFmpeg binaries.
- Implemented dual Unix domain socket IPC bridging TypeScript to the headless
  PyBoy worker for binary frame/audio streaming and NDJSON command framing.
- Hardened emulator IPC resilience with per-client bounded broadcast queues
  and drop-oldest eviction to eliminate socket backpressure deadlocks, while
  enforcing strict separation between 32KB cartridge SRAM and full save-states.
- Fixed checkpoint restoration ordering by invoking `loadBattery()` before
  `loadState()` (preventing cartridge loading from resetting PyBoy to frame 0)
  and guaranteed turn 0 initial state creation before advancing turns.
- Built an 11-state GameController lifecycle FSM with monotonic epoch fencing
  to prevent async turn completion races, binding automatic joypad button
  releases and manual lease cleanup to state transitions.
- Integrated a 64-bit perceptual hash (pHash) visual loop detector, multi-tier
  checkpoint retention, SHA-256 ROM verification, Zod action batch validation,
  and corrective reprompting (routing schema exhaustion to `NEEDS_ATTENTION`).
- Developed the Milestone 4 Hono spectator web application on port 4401 with
  real-time binary WebSocket streaming, session-based admin authentication
  hardened against null payloads, and a 500ms watchdog manual takeover lease.
- Built the Milestone 5 headless FFmpeg broadcast compositor featuring dynamic
  atomic drawtext overlay renames with percent-escaping, multi-RTMP tee muxing,
  and a PCM silence watchdog maintaining monotonic clock sync during pauses.
- Evaluated switching video encoding from H.264 to H.265, but retained H.264
  due to Twitch RTMP ingestion requirements and single-pass tee muxing
  constraints.
- Evaluated `gen1recomp` native recompiler architecture and decided to retain
  headless PyBoy for headless execution and deterministic frame-stepping
  requirements.
- Resolved spectator HLS player initialization loops, intro recording timing,
  and suppressed HTTP access log flooding.
- Corrected broadcast overlay alignment and dynamic model synchronization,
  eliminated audio static via an IIR DC blocker filter, and improved Game Boy
  control input registration.
- Configured broadcast stream video recording filenames to prefix
  human-readable timestamps followed by lowercase ROM names.
- Configured broadcast overlay to tail and display the most recent 6 lines of
  streaming LLM thoughts.
- Achieved a completely clean repository verdict across 4 opaque-box E2E test
  tiers and white-box adversarial stress tests (34 test suites, 486 tests).

## Media Pipelines & Generative Systems

- Hardened `podcast-generator` audio processing with robust Gemini chunk
  generation error handling, NFC Unicode normalization, and multi-strategy
  title matching to resolve episode deduplication issues.
- Implemented per-speaker backstories with Gemini TTS context separation,
  dynamic script formatting, markdown serialization, and a configurable
  friendly banter toggle (instructing hosts to greet each other before
  discussing topics when banter is disabled).
- Implemented structured speaker profile management and automated AI persona
  generation in `podcast-generator`, featuring Gemini TTS voice selection,
  clarified form fields, and in-memory PCM-to-WAV voice previews.
- Integrated Google Lyria 3 Clip into `media-generator` for generating,
  previewing, and assembling podcast intro and outro theme music with FFmpeg
  fading.
- Implemented EBU R128 loudness normalization across speech and background
  music using FFmpeg `loudnorm` in `media-generator`, placing `loudnorm` before
  `afade` to prevent gain over-compensation.
- Decided to scope the audiobook creation workflow in `media-generator` to
  selecting from generated books rather than arbitrary text file uploads, and
  analyzed full-bleed cover artwork prompt constructions.
- Added spaced ad read configuration and prompt integration to distribute ad
  placements evenly across podcast episodes (`k / (N + 1)` intervals),
  resolving frontend TypeScript typing with the `ad_reads` property.
- Enhanced podcast prompt generation with target episode length selection,
  automated preamble injection, `{{placeholder_title}}` template support, and
  episode title prefix directives.
- Added support for parenthetical title descriptions during prompt
  generation while preserving bare titles for deduplication, and confirmed
  that sequence detection relies on output folder names rather than JSON
  manifests.
- Resolved Gemini `PROHIBITED_CONTENT` blocks in `movie-generator` by
  setting `BLOCK_ONLY_HIGH` safety thresholds, de-escalating prompt
  guidelines, and implementing automated scene content sanitization.
- Analyzed `media-generator` scene chunking rules to determine why movie
  generation favors cut transitions over continuous shots during dialogue.
- Centralized default Gemini and Lyria model IDs in `shared/models.ts`
  (`DEFAULT_TEXT_MODEL`, `DEFAULT_IMAGE_MODEL`, `DEFAULT_AUDIO_MODEL`,
  `DEFAULT_VIDEO_MODEL`, `DEFAULT_MUSIC_MODEL`), stripping `models/` prefixes
  and excluding experimental or `latest` tags, and audited live API parity.
- Resolved Jellyfin 12 API integration across services by eliminating
  unnecessary user lookups under server API key auth in `media-generator`, and
  retrieving user IDs via `GET /Users` for episode metadata updates in
  `podcast-generator`.
- Migrated `podcast-generator` configuration (AI model selection and Slack
  webhook notifications) from user profiles to environment variables, and
  mapped disc numbers for "The Marauders" and "The Founders".

  documenting 17 findings and publishing a master audit report to the

  `authMiddleware` phantom user creation, fixed `fileStore` read side-effects

  immutability, form validation, and eliminated duplicate dashboard

  frontend and backend components, closing critical test coverage gaps in

  limiting, and RSS feed links in Slack notifications.

  HTTP 400 rejection on directory traversal attempts and enforcing CSRF origin
  validation.

  daemons by implementing live endpoint token polling, test fixture state
  isolation, and automatic token refresh retries in `AgentApiBridge`.
- Created and tested the `no-secrets-in-commits` rule in `antigravity-plugin`
  to block committing credentials or API keys to Git repositories.
- Created, configured, and tested a scheduled sidecar in `antigravity-plugin`
  to monitor and update default Gemini and Lyria models in `media-generator`
  with Slack notifications.
- Isolated unit test runs by mocking `NotificationManager` in
  `podcast-generator`, preventing live Slack notifications from leaking.
