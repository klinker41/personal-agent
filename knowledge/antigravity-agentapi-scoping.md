# Knowledge: Antigravity-Agentapi-Scoping

- The Antigravity Language Server enforces workspace scoping during `agy
agentapi new-conversation`; passing an `ANTIGRAVITY_PROJECT_ID` that does not
match the active workspace session's project UUID triggers a `PermissionDenied`
error.
