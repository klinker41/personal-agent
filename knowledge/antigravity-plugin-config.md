# Knowledge: Antigravity-Plugin-Config

- Local Antigravity plugins are configured in `~/.gemini/config/plugins.json`
under an `entries` array containing objects with `path` fields.

- Custom MCP server configurations can be placed at the plugin repository root
in `mcp_config.json` instead of the global Antigravity home directory
(`~/.gemini/antigravity-cli`).
