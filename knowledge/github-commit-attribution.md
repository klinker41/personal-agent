# Knowledge: Github-Commit-Attribution

- GitHub links a Co-authored-by: Name <email> commit trailer to a contributor
profile and avatar only when <email> belongs to a verified GitHub User account
or a GitHub App bot noreply address (<id>+<slug>[bot]@users.noreply.github.com,
though [bot] accounts are omitted from some contributor graphs); unlinked emails
like noreply@google.com render text-only co-author metadata with a generic icon.
